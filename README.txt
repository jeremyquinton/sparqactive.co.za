SPARQ ACTIVE — HTML + TAILWIND

Open index.html in a browser. Keep the assets folder beside it.
Upload index.html and assets/ to any static web host to publish.

Tailwind CSS v4 is loaded through its browser CDN, so an internet connection is required for styling. This is an editable, no-build version. For production, compile Tailwind to a static CSS file instead of using the browser CDN.

Edit the two marketplace URLs in index.html to use your storefront links. Currently they open Sparq Active search results.

The logo and photography are extracted from your supplied brand guide. Gotham webfont files were not supplied; a system-font fallback is used. Colours preserve the existing page, including its lighter #F5F5F4 background.
